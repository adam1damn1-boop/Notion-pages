function escapeHtml(value){
  return String(value).replace(/[&<>"']/g, ch => ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#039;'}[ch]));
}
function excerpt(text){
  const clean = text.split(". ").slice(0,2).join(". ");
  return clean.endsWith(".") ? clean : clean + ".";
}

## Отчёт по сайту

**Название концепции:** «Technika bez starostí / Техника без тревоги».

### Ассоциации из названия и текстов

1. **Спокойствие вместо паники** — тексты постоянно обещают объяснить всё простыми словами, без давления и спешки.
2. **Домашняя забота** — мастер приезжает домой, помогает родителям, детям, семье и малому бизнесу.
3. **Чистый воздух и порядок** — пыль, лишние программы, хаос в настройках превращаются в понятную систему.
4. **Мягкая безопасность** — камеры, сигнализация и умный дом поданы не агрессивно, а как способ легче уезжать и меньше тревожиться.
5. **Обучение с уважением к темпу** — важен не техно-пафос, а уверенность: «я справлюсь».

Финальный макет соответствует этим ассоциациям: использованы тёплый фон, мягкая мятно-песочная палитра, крупная дружелюбная типографика, большие округления, спокойные hover-эффекты и карточки без визуального шума.

### Визуальный стиль

- **Палитра:** тёплый бумажный фон, мята, песочный, мягкий коралл и спокойный сине-серый акцент.
- **Типографика:** Fraunces для крупных эмоциональных заголовков и Nunito Sans для дружелюбного, легко читаемого интерфейса.
- **Композиция:** на главной — hero с персонажем мастера, затем сетка из 12 услуг. На страницах услуг — разные высоты и направления hero-блоков, чтобы страницы не выглядели одинаково.
- **Микровзаимодействия:** плавный reveal при прокрутке, приподнимание карточек, подмена `--main` на `--hover` только в сетке услуг на `index.html`.
- **Адаптивность:** сетка перестраивается с 3–4 колонок на 2 и затем на 1 колонку; страницы услуг переходят в одноколоночный вид.

### Проверка структуры

- Есть `index.html`, 12 отдельных страниц услуг и `kontakt.html`.
- Все ссылки относительные: `./index.html`, `./kontakt.html`, `./имя-файла.html`.
- Все 12 услуг присутствуют и связаны со slug изображений:
    - `cleaning` → 1.1
    - `upgrade` → 1.2
    - `software` → 1.3
    - `repair` → 1.4
    - `webcam` → 2.1
    - `alarm` → 2.2
    - `appliances` → 2.3
    - `literacy` → 3.1
    - `tutor` → 3.2
    - `chess` → 3.3
    - `development` → 3.4
    - `design` → 4
- Тексты вынесены в `js/i18n.js` в словарь `cs`.
- Переключатель языка предусмотрен; активен чешский, английская кнопка отключена до добавления словаря `en`.
- Для контактов оставлены рабочие места подключения: `mailto:` и ссылка на мессенджер. Перед публикацией нужно заменить `kontakt@example.com` и `https://wa.me/` на реальные данные.

## Инструкция по сборке

1. Создайте папку проекта.
2. Разложите файлы из свойств записи:
    - из свойства **Html** — все `.html` файлы в корень проекта;
    - из свойства **Styles** — файл `css/styles.css`;
    - из свойства **Scripts** — файл `js/i18n.js`;
    - из свойства **Other** — `vercel.json`, `robots.txt`, `README.md`.
3. Создайте папку `img`.
4. Скопируйте изображения из страницы Main images в папку `img` и переименуйте строго по схеме:
    - `slug--main.png`
    - `slug--hover.png`
5. Проверьте, что в папке есть все пары:
    - `hero`, `cleaning`, `upgrade`, `software`, `repair`, `webcam`, `alarm`, `appliances`, `literacy`, `tutor`, `chess`, `development`, `design`.
6. Откройте `index.html` локально в браузере.
7. Замените контактные заглушки:
    - `kontakt@example.com`
    - `https://wa.me/`
8. Если нужен второй язык, добавьте в `I18N` объект `en` и снимите `disabled` с кнопки EN в HTML-файлах.

## Развёртывание на Vercel

1. Создайте новый проект в Vercel.
2. Загрузите папку проекта через Git-репозиторий или Vercel CLI.
3. Framework Preset оставьте как **Other** / static.
4. Build Command не указывайте.
5. Output Directory оставьте пустым или `.`.
6. После деплоя откройте главную страницу и проверьте:
    - загрузку CSS и JS;
    - переходы между 12 страницами услуг;
    - `kontakt.html`;
    - отображение всех изображений из `./img/`;
    - hover-подмену изображений только на главной;
    - работу на мобильной ширине.
7. Подключите домен в настройках Vercel при необходимости.

## Контроль качества

Код сделан без сборки и без серверной части. HTML использует валидную базовую структуру HTML5. CSS построен на Grid/Flexbox, содержит адаптивные брейкпоинты и `prefers-reduced-motion`. JS не использует внешние платные API, отвечает за рендер словаря, страницы услуг, контактной страницы, reveal-анимацию и переключатель языка.
