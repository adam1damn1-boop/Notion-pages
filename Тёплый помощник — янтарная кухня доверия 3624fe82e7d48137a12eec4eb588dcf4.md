# 🤝 Тёплый помощник — янтарная кухня доверия

## 1. Отчёт по сайту

### Концепция

Макет «Янтарная кухня доверия» выведён из имени записи «Тёплый помощник» и из тёплых, неторопливых чешских текстов записи. Это не технический лендинг, а домашняя витрина: кремовый фон, янтарная акцентная нота, карточки с мягкими тенями, серифный Fraunces в заголовках и гуманистический Nunito в теле.

### Ассоциации, лёгшие в основу

1. Кремовая янтарная палитра — тёплый вечер дома.
2. Округлые формы и мягкие тени — никакой техно-агрессии.
3. Серифный заголовочный шрифт — доверие, уют, «рука хорошего мастера».
4. Неторопливые микровзаимодействия: плавный hover-swap, fade-in по скроллу, приподнятие карточек.
5. Рефрен «выезд и первая проверка бесплатно» — вынесён в eyebrow-маркер в hero и в блоке контакта.

### Цвета и типография

- Фон: `#fbf5ea` (тёплый крем).
- Акцент: `#c47a3c` (янтарь) / `#a05f29` (hover).
- Мягкий фон карточек: `#f5ead4`, рамка `#e2cda5`.
- Текст: `#2b1d12` (основной), `#5b4836` (мягкий).
- Шрифты: **Fraunces** (заголовки) + **Nunito** (тело), оба через Google Fonts.

### Композиция и структура

- `index.html` — hero с мастером (`hero--main.png`), сетка из 12 карточек с hover-swap (`-main` → `-hover`), сгруппированных по 4 категориям, и контактный блок с повторным изображением мастера (`hero--hover.png`).
- 12 отдельных страниц услуг — каждая с hero (`-main` как обложка, без hover), телом текста и контекстной иллюстрацией (`-hover`) внутри прозы. Внизу — прев/некст-навигация и возврат на «Дому».
- `kontakt.html` — отдельная страница с контактами (mailto, tel, WhatsApp, Telegram) и крупным портретом мастера.
- Для визуального разнообразия страницы услуг используют модификаторы hero: default, `--reverse`, `--tall`, `--centered`, `--compact`. Соседние страницы визуально отличаются по высоте и композиции hero.

### Приёмы

- CSS Grid + Flexbox, mobile-first (брейкпоинты 620, 720, 820, 880, 920 px).
- Hover-swap по наведению только на миниатюрах индекса; на страницах услуг эффект отключён.
- IntersectionObserver для fade-in блоков с классом `.reveal`.
- `loading="lazy"` для всех иллюстраций кроме hero.
- `prefers-reduced-motion: reduce` отключает все анимации.
- Доступность: skip-link, `aria-pressed` на языковом переключателе, контрастные цвета, alt-тексты из [Main images].

### Мультиязычность

- Словарь в `assets/js/i18n.js` (объект `window.SITE_I18N`).
- Атрибуты `data-i18n` и `data-i18n-attr` подменяются при загрузке и при клике по кнопке языка.
- Сейчас доступен только `cs`; добавить язык = дописать ключ в `SITE_I18N` и кнопку `<button class="lang__btn" data-lang="xx">`.

### Проверка качества

- Все 12 услуг присутствуют на индексе и имеют отдельную страницу.
- Связки `slug → -main.png/-hover.png` совпадают с [Main images]: cleaning, upgrade, software, repair, webcam, alarm, appliances, literacy, tutor, chess, development, design + hero.
- Шапка, футер и языковой переключатель дублируются на каждой странице.
- Ссылки относительные (`./...`), работает без серверных redirect-правил.

### Как разложить файлы из свойств записи

- **Html** — все страницы. Каждый блок `=== имя.html ===` → отдельный файл в корне проекта. Блок `=== _service-page-template ===` — это шаблон для быстрого воспроизведения остальных страниц услуг (`chess.html`, `tutor.html`, `development.html`, `design.html`) по аналогии с уже выписанными — подставьте SLUG, CAT, PREV, NEXT и MODIFIER из таблицы. Шапка и футер берутся из любой из уже выписанных страниц (они идентичны).
- **Styles** — весь CSS, кладётся в `assets/css/style.css`.
- **Scripts** — два файла:
    - `assets/js/i18n.js` — словарь языков.
    - `assets/js/main.js` — логика i18n, fade-in, smooth-scroll.
- **Other** — `package.json`, `vercel.json`, `robots.txt`, `manifest.webmanifest` в корне; `img/README.txt` помогает разложить картинки.

### Папка `./img/`

Скачайте 26 PNG со страницы [Main images](https://www.notion.so/Main-images-3614fe82e7d4800891eacef2c9d4ab58?pvs=21) и сохраните в `img/` с исходными именами (`slug--main.png`, `slug--hover.png`). Альт-тексты в макете уже совпадают с полями `alt` из [Main images].

### Переключение языков

- По умолчанию — `cs`. Выбор хранится в `localStorage` (`tp_lang`).
- Чтобы добавить, например, русский:
    1. Дописать `ru: { ... }` в `SITE_I18N` (ключи те же).
    2. Добавить кнопку `<button class="lang__btn" data-lang="ru">RU</button>` в `.lang` на каждой странице.
- Никакой сборки не требуется.

## 3. Развертывание на Vercel (или аналоге)

### Вариант А: через Vercel CLI

1. Установите Node.js ≥ 18.
2. В терминале выполните:
    
    ```bash
    npm i -g vercel
    vercel login
    cd teply-pomocnik
    vercel
    ```
    
3. Приимите предложенные настройки: Framework Preset = `Other`, Build Command — пусто, Output Directory = `./`.
4. Для прода-деплоя: `vercel --prod`.

### Вариант Б: через Git + Vercel дашборд

1. Создайте репозиторий на GitHub/GitLab и залейте все файлы (включая `img/`).
2. На [vercel.com](http://vercel.com) → *Add New* → *Project* → импорт репозитория.
3. Build Settings: Framework = `Other`, Build = пусто, Output = `./` (определяется из `vercel.json`).
4. Нажмите *Deploy*. Через ~30 секунд сайт будет доступен на `https://<project>.vercel.app`.

### Аналоги

- **Netlify**: drag-and-drop папки в [app.netlify.com/drop](http://app.netlify.com/drop), или подключить репо и оставить Build command пустым.
- **Cloudflare Pages**: импорт репо, Build command пусто, Output directory `/`.
- **GitHub Pages**: включить Pages в настройках репо, источник — ветка `main` / `/`.

### Домен

- После деплоя в Vercel зайдите в *Settings → Domains*, добавьте свой домен (например `teply-pomocnik.cz`) и создайте у регистратора запись CNAME на `cname.vercel-dns.com` (или A-запись на `76.76.21.21`).
- HTTPS-сертификат Vercel выпустит сам.
- Проверьте открываемость `/index.html`, `/cleaning.html` и `/kontakt.html`, а также что переключатель языка сохраняет выбор при переходе между страницами.
