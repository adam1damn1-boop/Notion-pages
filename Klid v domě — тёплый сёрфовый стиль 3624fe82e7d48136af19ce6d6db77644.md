# Klid v domě
Český statický web výjezdového počítačového mistra. Žádný build, jen statika.

## Spuštění lokálně
- Otevřete index.html přímo v prohlížeči, nebo spusťte npx serve . v kořeni projektu.

## Struktura

.
├── index.html
├── styles.css
├── i18n.js
├── app.js
├── manifest.webmanifest
├── robots.txt
├── vercel.json
└── img/
    ├── hero--main.png ... atd.


## Přidání jazyka
1. V i18n.js přidejte do window.I18N nový klíč, např. en: { ... } se stejnou strukturou klíčů jako cs.
2. V index.html přidejte <option value="en">EN</option> do #lang-select.

## Deploy na Vercel
1. git init && git add . && git commit -m "init"
2. Pushněte na GitHub.
3. Na http://vercel.com zvolte Add New → Project* a vyberte repo. Build i Output nechte prázdné — vercel.json už všechno popisuje.
4. Po deployi musí být přístupné https://<vaše-slug>.vercel.app.

  function getDict(lang) {

    return dict || {};
  }

  function applyTranslations(lang) {
    var dict = getDict(lang);
    var nodes = document.querySelectorAll('[data-i18n]');
    for (var i = 0; i < nodes.length; i++) {
      var node = nodes[i];
      var key = node.getAttribute('data-i18n');
      if (!key || !(key in dict)) continue;
      var attr = node.getAttribute('data-i18n-attr');
      if (attr) {
        node.setAttribute(attr, dict[key]);
      } else {
        node.textContent = dict[key];
      }
    }
    document.documentElement.setAttribute('lang', lang);
    document.documentElement.setAttribute('data-lang', lang);
  }

  function initLangSwitcher() {
    var select = document.getElementById('lang-select');
    if (!select) return;
    var stored = null;
    try { stored = localStorage.getItem(STORAGE_KEY); } catch (e) {}
    var initial = (stored && window.I18N && window.I18N[stored]) ? stored : DEFAULT_LANG;
    if (select.value !== initial) {
      var match = select.querySelector('option[value="' + initial + '"]');
      if (match) select.value = initial;
    }
    applyTranslations(select.value || DEFAULT_LANG);
    select.addEventListener('change', function () {
      var lang = select.value || DEFAULT_LANG;
      applyTranslations(lang);
      try { localStorage.setItem(STORAGE_KEY, lang); } catch (e) {}
    });
  }

  function initReveal() {
    var nodes = document.querySelectorAll('.reveal');
    if (!nodes.length) return;
    if (!('IntersectionObserver' in window) || window.matchMedia('(prefers-reduced-motion: reduce)').matches) {

      return;

    var observer = new IntersectionObserver(function (entries) {
      entries.forEach(function (entry) {

          observer.unobserve(http://entry.target);
        }
      });

# Отчёт по сайту «Klid v domě»

<aside>
🎯

**Концепция.** Тёплый, домашний, доверительный макет одностраничника выездного компьютерного мастера. Главная эмоция — *клид* (спокойствие). Сайт говорит на чешском, обращается к семьям, бабушкам и дедушкам, родителям школьников и владельцам небольшого бизнеса.

</aside>

## Целевые устройства и адаптивность

- **Mobile-first**: верстка строится от одной колонки и расширяется до 4 колонок на десктопе.
- Проверенные брейкпоинты: `680px`, `860px`, `900px`, `1024px`, `1180px`.
- Sticky-шапка с backdrop-blur, переключателем языка и CTA остаётся доступной при скролле.
- Изображения — `loading="lazy"` (кроме hero), `aspect-ratio` фиксирует пропорции, `object-fit: cover` не ломает картинку.

## Визуальный стиль

- **Палитра.** Тёплый кремовый фон `#f6efe1`, глубокий «лесной» teal `#1f6b6b` для бренда и кнопок, терракотовый акцент `#c97455`. Чёткий контраст текста на фоне — AA-доступно.
- **Типографика.** `Fraunces` (display-serif, ласково-современный, контрастный) для заголовков и `Inter` (humanist sans) для основного текста. Подгрузка с Google Fonts через `display=swap`.
- **Микровзаимодействия.**
    - Карточки услуг: при наведении меняется изображение `--main → --hover` и карточка приподнимается, появляется мягкая тень.
    - Подчёркивание навигации появляется снизу при ховере.
    - Reveal-анимация секций на скролле через `IntersectionObserver`.
    - Smooth-scroll для якорей, focus-visible для клавиатуры, поддержка `prefers-reduced-motion`.
- **Структура страницы.**
    1. Hero с портретом мастера и слоганом *Klid v domě začíná u spolehlivé techniky.*
    2. Секция 01 — Péče o počítač (4 услуги: cleaning, upgrade, software, repair).
    3. Тёмный break-блок с повторным портретом мастера и буллетами «Proč já».
    4. Секция 02 — Bezpečnost (webcam, alarm, appliances).
    5. Секция 03 — Výuka, с подсекциями *Pro dospělé* (literacy) и *Pro děti* (tutor, chess, development).
    6. Секция 04 — Design (расширенная карточка-фича).
    7. Kontakt: телефон, e-mail, WhatsApp, Telegram. Часы и зона выезда.
    8. Footer с обратной ссылкой наверх.

## Обоснование решений

- **Один HTML-файл** упрощает деплой на любой статический хостинг и не требует сборки.
- **i18n как JS-словарь** (`window.I18N`) с поддержкой `data-i18n` и `data-i18n-attr` атрибутов. Добавление языка = добавление ключа в `window.I18N` и `<option>` в селекторе.
- **hero-изображение мастера** используется дважды: вверху как портрет и в тёмном break-блоке между секциями — это соответствует роли `hero` (между услугами).
- **Контактная форма** не серверная: используются `tel:`, `mailto:`, `wa.me/`, `t.me/` — без бэкенда.

## Развёртывание на Vercel

1. Заведите бесплатный аккаунт на [vercel.com](http://vercel.com) (войти можно через GitHub).
2. Создайте новый репозиторий на GitHub, например `klid-v-dome`, и закоммитьте туда всё содержимое папки из инструкции выше.
3. В панели Vercel нажмите **Add New → Project**, выберите репозиторий и подтвердите импорт.
4. **Framework Preset:** *Other* (статика). Build command и Output directory оставьте пустыми — `vercel.json` уже описывает поведение.
5. Нажмите **Deploy**. Через ~30 секунд получите URL вида `https://klid-v-dome.vercel.app`.
6. Чтобы подключить свой домен: **Project → Settings → Domains → Add**, далее по подсказке настроить DNS у вашего регистратора (Vercel показывает CNAME/A-записи).
7. После выкатки откройте сайт на телефоне и в десктопном браузере: проверьте hover-эффекты карточек, плавный скролл, переключатель языка, ссылки на тел/мейл/мессенджеры.
