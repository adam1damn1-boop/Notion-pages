(function () {
  var LANG_KEY = 'siteLang';
  function dict() { return window.DICT || { cs: {} }; }
  function currentLang() {
    var l = localStorage.getItem(LANG_KEY);
    if (!l || !dict()[l]) l = 'cs';
    return l;
  }
  function t(key) {
    var l = currentLang();
    var d = dict();
    return (d[l] && d[l][key]) || (d.cs && d.cs[key]) || '';
  }
  function applyI18n() {
    var lang = currentLang();
    document.documentElement.setAttribute('lang', lang);
    var nodes = document.querySelectorAll('[data-i18n]');
    for (var i = 0; i < nodes.length; i++) {
      var el = nodes[i];
      var key = el.getAttribute('data-i18n');
      var val = t(key);
      if (!val) continue;
      if (el.hasAttribute('data-i18n-html')) el.innerHTML = val;
      else el.textContent = val;
    }
  }
  function paintLangSwitch() {
    var lang = currentLang();
    var btns = document.querySelectorAll('.lang button[data-lang]');
    for (var i = 0; i < btns.length; i++) {
      btns[i].classList.toggle('is-active', btns[i].dataset.lang === lang);
    }
  }
  function setLang(l) {
    if (!dict()[l]) return;
    localStorage.setItem(LANG_KEY, l);
    applyI18n();
    paintLangSwitch();
  }

  document.addEventListener('DOMContentLoaded', function () {
    applyI18n();
    paintLangSwitch();

    var btns = document.querySelectorAll('.lang button[data-lang]');
    for (var i = 0; i < btns.length; i++) {
      (function (b) {
        b.addEventListener('click', function () {
          if (b.disabled) return;
          setLang(b.dataset.lang);
        });
      })(btns[i]);
    }

    var tgl = document.querySelector('.menu-toggle');
    var nav = document.querySelector('.nav');
    if (tgl && nav) {
      tgl.addEventListener('click', function () { nav.classList.toggle('open'); });
    }

    if ('IntersectionObserver' in window) {
      var io = new IntersectionObserver(function (entries) {
        entries.forEach(function (e) {
          if (e.isIntersecting) {
            http://e.target.classList.add('in');
            io.unobserve(http://e.target);
          }
        });
      }, { threshold: 0.12, rootMargin: '0px 0px -60px 0px' });
      document.querySelectorAll('.reveal').forEach(function (el) { io.observe(el); });
    } else {
      document.querySelectorAll('.reveal').forEach(function (el) { el.classList.add('in'); });
    }

    // Touch fallback: tap card to swap to hover image, second tap navigates
    document.querySelectorAll('.card').forEach(function (c) {
      c.addEventListener('touchstart', function () { c.classList.add('is-hover'); }, { passive: true });
    });

    var y = document.querySelector('[data-year]');
    if (y) y.textContent = new Date().getFullYear();
  });
})();

# 🕰️ Отчёт по сайту «С заботой о времени»

## Концепция

Макет построен вокруг идеи **«тёплый минимализм. Часы у камина»**: выездной мастер показан не как сервис-провайдер, а как спокойный сосед, который возвращает человеку время и тишину. Главный слоган — *«Technika má pomáhat, ne brát čas a klid»*.

## 3–5 ассоциаций, выведённых из имени и текстов

1. **Время как ценность** — бережный ритм отведённых на выход, крупный серифный заголовок, воздух.
2. **Соседская теплота** — кремовый фон, мягкие градиенты, терракотовый акцент вместо корпоративного синего.
3. **Прозрачность вместо продажи** — повторяемый бейдж *«výjezd a první diagnostika zdarma»* и честная интонация в блоках.
4. **Тишина после ремонта** — минимум анимаций, только фейды и мягкие подъёмы карточек.
5. **Книга полезных советов** — буквица в первом абзаце каждой страницы услуги, гуманистическая засечка Fraunces.

## Ключевые приёмы дизайна

- **Палитра:** фон `#FAF6EF`, бумага `#FFFFFF`, текст `#2A2F36`, приглушённый `#6C7480`, терракотовый акцент `#C9763F`, линии `#E8E1D3`.
- **Типографика:** Fraunces (заголовки, италик-акценты, буквицы) + Inter (основной текст). Оба шрифта — Google Fonts, бесплатны.
- **Композиция:** Grid 12-колоночный в гридах 4×1, 4×2, 1, макс. ширина 1180 px.
- **Микровзаимодействия:** fade-in при прокрутке (IntersectionObserver), hover-swap изображений только на миниатюрах индекса, лёгкий lift карточек, smooth-scroll по якорям.
- **Структура:** `index.html` → 12 страниц услуг → `kontakt.html`. Для визуального ритма четные страницы (upgrade, repair, alarm, literacy, chess, design) используют класс `svc-hero.tall` — более высокий hero с расширенным полем для иллюстрации.
- **Hero-вставка мастера:** на индексе размещён блок `·intermission·` между группами «Безопасность» и «Учёба» — фото мастера (`hero--main` → `hero--hover` при наведении) + приглашение позвонить.
- **Изображения:** пары `slug--main`/`slug--hover` из `./img/`. На индексе — hover-swap (CSS opacity-fade). На странице услуги — `main` как hero, `hover` как вторая иллюстрация в sticky-блоке `svc-illu`, без hover-эффекта.
- **Доступность:** видимый `:focus-visible`, alt-тексты, `prefers-reduced-motion` отключает анимации, контрастный текст на фоне.
- **Мобильные:** брейкпоинты 960 px и 540 px. Сетка услуг: 4—2—1 колонки. Меню сворачивается в кнопку `☰`.

## Целевые устройства

Настольные экраны (1024–1440 px) и мобильные (от 360 px). Сайт полностью адаптивен, работает без JS (фолбек `.reveal` выводит блоки без анимации).

## Обоснование решений

Имя записи *«C заботой о времени»* задаёт ритм всего макета: никакого техно-блеска, хаотичных анимаций или агрессивных CTA. Тексты услуг («приеду здарма», «техника не обязательно на отпис», «без спешки и сложных слов») подкрепляют интонацию: я выбрал гуманистическую засечку (Fraunces) вместо геометрического гротеска и буквицу в первом абзаце, чтобы страница услуги читалась как «глава книги», а не лендинг.

## Куда класть файлы из свойств записи

- **Html** — все 14 HTML-файлов в корень проекта. Для каждой страницы услуги возьмите базовый шаблон из свойства Html и подставьте значения `{slug}`, `{code}`, `{title}`, `{group}`, `{lead}`, `{p1}`, `{p2}`, `{prev}`, `{prevTitle}`, `{next}`, `{nextTitle}`, `{tallClass}` из таблицы в конце свойства Html. Для `{tallClass}` либо вставьте `tall`, либо оставьте пустым.
- **Styles** — содержимое идёт в `styles.css` в корне.
- **Scripts** — разделите на два файла по маркерам `=== i18n.js ===` и `=== script.js ===` в корне.
- **Other** — `vercel.json`, `robots.txt`, `sitemap.xml`, `manifest.webmanifest` ложатся в корень.

## Папка `./img/`

Скопируйте 26 изображений со страницы Маин имагес в папку `img/` в корне. Имена файлов должны совпадать с `slug--main.png` и `slug--hover.png` из манифеста. Оригинальные имена (например `master01.png` → `hero--main.png`, `camera01.png` → `webcam--main.png`) переименуйте вручную или скриптом.

## Как переключать языки

- Основной язык — `cs`. Словарь живёт в `i18n.js` в виде `window.DICT = { cs: { ... } }`.
- Чтобы добавить блок `en` (или любой другой): скопируйте блок `cs`, переведите все значения, в HTML-файлах уберите `disabled` у `<button data-lang="en">`.
- Язык запоминается в `localStorage` под ключом `siteLang`. Первичный язык — `cs`. Будущие языки переключаются кнопками CS / EN в шапке.

## Локальный запуск

Сайт — чистые статические файлы, без сборки. Проверить можно любым статическим сервером, например:

```
npx serve .
# или
python3 -m http.server 8080
```

# ▲ Развёртывание на Vercel

## Вариант 1 — Drag & drop

1. Перейти на [vercel.com/new](http://vercel.com/new), войти в аккаунт (Free Hobby план).
2. Нажать **«Add New» → «Project» → «Continue with another method» → «Deploy directory»**.
3. Перетащить папку со всеми файлами (`index.html`, остальные HTML, `styles.css`, скрипты, `img/`).
4. Framework Preset оставить **Other**, Build Command пустым, Output Directory — корень.
5. Нажать **Deploy**. Через ~10 сек Vercel выдаст URL вида `your-project.vercel.app`.

## Вариант 2 — Через GitHub

1. Создайте пустой репозиторий на GitHub.
2. Разложите файлы из этой записи по структуре выше, сделайте `git init`, `git add .`, `git commit -m "Initial site"` и `git push`.
3. На [vercel.com/new](http://vercel.com/new) выберите **Import Git Repository**, укажите ваш репозиторий.
4. Настройки:
    - Framework Preset — **Other**.
    - Root Directory — `./`.
    - Build Command — пусто.
    - Output Directory — пусто (или `.`).
5. Vercel автоматически подхватит `vercel.json` (cleanUrls, кэш-заголовки) и опубликует сайт. Каждый push — новый деплой.

## Проверка домена

1. Откройте `your-project.vercel.app` — должна появиться главная страница с hero-блоком и сеткой из 12 услуг.
2. Проверьте переходы: index → любая услуга → prev/next → kontakt.
3. На мобильном устройстве откройте тот же URL и убедитесь, что меню сворачивается в «бургер».
4. Для своего домена: в проекте Vercel → **Settings → Domains → Add** — укажите ваш домен и добавьте DNS-записи (A `76.76.21.21` или CNAME на `cname.vercel-dns.com`).

## Альтернативы

- **Netlify Drop:** [app.netlify.com/drop](http://app.netlify.com/drop) — перетащить папку.
- **GitHub Pages:** включить в Settings → Pages в вашем GitHub-репозитории (Branch: `main`, folder `/`).
- **Cloudflare Pages:** Connect to Git → Framework `None` → Build command пусто.

Сайт не требует бэкенда, базы данных или платных API. Всё работает на бесплатных тарифах.
