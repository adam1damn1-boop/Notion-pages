## 📋 Отчёт по сайту

### Концепция

**«Dům bez shonu»** («Дом без суеты») — тёплая, домашняя визуальная история о выездном компьютерном мастере для жителей Чехии. Сайт говорит спокойно, без техножаргона и обещаний-чудес. Главный посыл: *«Technika má doma pomáhat, ne přidělávat starosti»* — техника дома должна помогать, а не добавлять забот.

### Целевые устройства

- Mobile-first с брейкпоинтом **880px** для перехода в двухколоночные раскладки.
- Гибкая сетка карточек `repeat(auto-fit, minmax(...))` — органично адаптируется от 320px до больших мониторов.
- Проверенные ширины: 320 / 414 / 768 / 1024 / 1280 / 1440px.

### Палитра

- Фон молочный крем `#f8f3eb`, вторичный тёплый бежевый `#efe6d6`.
- Поверхность `#ffffff`.
- Текст `#1f2a2a`, приглушённый `#5d6b6a`.
- Основной — глубокий тил `#2c4a47`.
- Акцент — тёплая терракота `#c97852`, мягкий `#f1c9b3`.

### Типографика

- Заголовки — **Fraunces** (мягкий современный serif с лёгкой курсивной подписью для подзаголовков).
- Тело и интерфейс — **Inter** (универсальный, отлично читается).
- Шрифты подключены через Google Fonts с `preconnect` и `display=swap`.

### Ключевые приёмы

1. **Hover-swap карточек.** При наведении основная картинка `--main` плавно перетекает в `--hover` через противоположную прозрачность и лёгкий зум. На сенсорных экранах swap включается тапом по карточке.
2. **Скролл-анимации.** Лёгкое появление секций и карточек через `IntersectionObserver` (`opacity` + `translateY`). Полностью отключается при `prefers-reduced-motion: reduce`.
3. **Четыре секции + контакт.** Péče → Bezpečí → Výuka (с подгруппами «Pro dospělé» / «Pro děti») → Design → Kontakt.
4. **Контраст секций.** Чередование белого (`group`), тёплого бежевого (`group--alt`) и тёмного фирменного (`group--design`) фона делает скролл живым, но не пёстрым.
5. **Pill-кнопки.** Сплошная primary и ghost-вариант, мягкая тень и подъём при hover.
6. **Мобильный навигатор.** Гамбургер раскрывается плавным выезжающим списком ссылок, закрывается при клике по пункту и при возврате к десктопной ширине.
7. **Доступность.** Skip-link, `aria-label`, контраст ≥ 4.5:1, фокусные обводки, `loading="lazy"` для карточек.

### Мультиязычность

- Все строки вынесены в `i18n.js` (`window.I18N.cs`). Текст подставляется по атрибуту `data-i18n="раздел.ключ"`.
- Alt-тексты картинок берутся из `I18N.<lang>.alt[slug]`.
- Выбор языка хранится в `localStorage` (`dbs.lang`).
- В шапке предусмотрен переключатель **CS / EN**. Для EN добавлено пустое пространство `I18N.en = {}` — при попытке клика кнопка слегка «качается». Чтобы запустить английскую версию, достаточно заполнить этот объект теми же ключами.

### Контакт

- Кликабельные строки `tel:`, `mailto:`, ссылки на WhatsApp и Telegram (замените на актуальные).
- Форма обратной связи отправляется через бесплатный сервис **FormSubmit** (`action="https://formsubmit.co/<email>"`). Сервер не нужен. При необходимости можно заменить на Web3Forms, Getform или Formspree.

## 🚀 Развёртывание на Vercel

### Вариант A. Через Git

1. Создайте новый репозиторий на GitHub / GitLab / Bitbucket и загрузите содержимое папки `dum-bez-shonu/`.
2. Откройте `vercel.com/new`, нажмите **Import Git Repository** и выберите свой репозиторий.
3. Vercel сам определит проект как статический. **Framework Preset:** `Other`. Команды установки и сборки оставьте пустыми. **Output Directory:** `.` (корень).
4. Нажмите **Deploy** — через минуту сайт будет доступен по URL вида `dum-bez-shonu.vercel.app`.

### Вариант B. Через CLI (drag & drop)

1. Установите CLI: `npm i -g vercel` (или используйте `npx vercel`).
2. В папке проекта выполните `vercel --prod`. Vercel задаст пару вопросов и опубликует сайт. Настройки кеширования возьмутся из `vercel.json`.

### Подключение собственного домена

1. В Vercel: **Project → Settings → Domains** → добавьте свой домен (например, `dumbezshonu.cz`).
2. Vercel выдаст DNS-записи: A `76.76.21.21` для корня и CNAME `cname.vercel-dns.com` для `www`.
3. Пропишите эти записи у регистратора домена. HTTPS-сертификат подключается автоматически (обычно в течение нескольких минут).

### Альтернативные хостинги

- **Netlify** — перетащите папку на `app.netlify.com/drop`.
- **GitHub Pages** — `Settings → Pages → Deploy from branch`.
- **Cloudflare Pages** — `Create a project → Direct Upload`.

Все три варианта работают без правок: сайт целиком статический и не зависит от Node.js.
