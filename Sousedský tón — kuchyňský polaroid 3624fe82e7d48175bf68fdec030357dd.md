# Соседский тон — отчёт о сборке сайта

## Концепция и визуальный язык

Имя записи — *«Соседский тон»* — задало главный образ: это не агентство и не сервис-центр, а сосед, который разбирается в компьютерах и просто заглянет к вам. Из текста контента в карточке (бесплатный выезд, первая диагностика бесплатно, 12 услуг от чистки ПК до шахмат с детьми) выросло несколько ассоциаций, которые я и попыталась удержать в дизайне:

- **Кухонный стол соседа.** Тёплая бумага, чуть наклонённые полароидные рамки, рукописная подпись курсивом — всё должно выглядеть так, будто вас усадили за стол и разговор идёт без давления.
- **Чешская мастерская.** Глиняная терракота, оливковый/шалфейный зелёный для «гарантийной» плашки бесплатного выезда, тёплая кремовая бумага вместо стерильного белого.
- **Полароид с двумя кадрами.** Каждая услуга показана двумя картинками: основная — спокойный «парадный» снимок, на ховере — живой контекст. На карточках это переключение по hover; на странице услуги ховер-картинка уже не висит на главной, а лежит рядом как «второй кадр».
- **Газетная типографика.** Заголовки — Fraunces (серифный, с живой курсивной формой), текст — Nunito (мягкий, плотный, читаемый). Курсивные подзаголовки и кикеры работают как чернильные пометки.

## Структура сайта

Сайт — статический, без сборщика и без SPA. Каждая страница самостоятельная, шапка и подвал дублируются. Всего 14 HTML-страниц:

- `index.html` — главная: hero с полароид-портретом мастера, 12 карточек услуг с эффектом смены изображения при наведении (main → hover), баннер «достаточно короткого сообщения».
- 12 страниц услуг — по одному файлу на услугу. Чтобы страницы не выглядели как близнецы, в hero меняется композиция по атрибуту `data-variant`:
    - `left` — текст слева, картинка справа (cleaning, software, alarm, tutor, design),

- `kontakt.html` — отдельная контактная страница с четырьмя каналами связи (e-mail, телефон, WhatsApp, Signal). Контакты — плейсхолдеры, замените на реальные.

Внутри каждой страницы услуги ниже hero идёт «второй кадр» (`--hover` картинка) рядом с подробным текстом, ниже — нижняя навигация *предыдущая ↔ следующая услуга*. На страницах услуг ховер-эффект на картинках уже не используется — изображение `--hover` показано рядом с текстом.

## Переключатель языка

Языки переключаются клиентским скриптом `i18n.js` + `scripts.js`:

- Все переводимые элементы помечены атрибутом `data-i18n="ключ"`.
- Полный словарь лежит в `window.I18N.cs` (чешский, основной) и `window.I18N.en` (английский, сокращённый).
- При загрузке страницы скрипт читает выбранный язык из `localStorage` (`sousedsky-lang`), по умолчанию `cs`. Если в выбранном языке ключа нет, используется чешский как фолбэк, чтобы текст никогда не пропадал.
- Кнопки `CS / EN` в шапке меняют активный язык, состояние подсвечивается классом `.active`.

Чтобы добавить переводы для остальных услуг на английский, достаточно дополнить блок `en` в `i18n.js` теми же ключами, что и в `cs`.

## Инструкция по сборке и публикации

1. Создайте локально папку проекта (например, `sousedsky-ton/`).
2. Перенесите содержимое каждого файла из соответствующего свойства этой страницы в реальный файл: блоки разделены строкой `=== имя_файла ===`. Свойства:
    - **Html** — все 14 HTML-страниц.
    - **Styles** — `styles.css`.
    - **Scripts** — `i18n.js` и `scripts.js`.
    - **Other** — `vercel.json`, `robots.txt`, `manifest.webmanifest`, `README.txt`.
3. Создайте подпапку `img/` и положите туда 26 PNG-файлов из списка выше. Имена должны совпадать с теми, что используются в HTML и CSS, иначе картинки не подгрузятся.
4. Откройте `index.html` локально в браузере, чтобы проверить, что всё работает (карточки переключают картинку, переключатель CS/EN меняет тексты, ссылки на услуги открываются).
5. Замените заглушки контактов в `kontakt.html` (`soused@example.cz`, `+420 777 123 456`) на реальные перед публикацией.

## Публикация на Vercel

Сайт статический, поэтому ничего собирать не нужно — Vercel будет раздавать файлы как есть.

1. Поместите папку проекта под Git: `git init && git add . && git commit -m "Sousedský tón — initial site"`.
2. Запушьте репозиторий на GitHub / GitLab / Bitbucket.
3. Зайдите на [vercel.com](http://vercel.com), нажмите **Add New → Project** и выберите репозиторий.
4. На шаге настройки укажите:
    - **Framework Preset:** *Other* (никакого билда не нужно).
    - **Build Command:** оставьте пустым.
    - **Output Directory:** оставьте пустым (Vercel возьмёт корень репозитория).
5. Нажмите **Deploy**. Через несколько секунд получите домен вида `sousedsky-ton.vercel.app`.
6. Для собственного домена (например `sousedskyton.cz`) откройте *Settings → Domains*, добавьте домен и пропишите DNS-записи у регистратора по подсказке Vercel.
7. Файл `vercel.json` уже добавляет долгое кеширование для статики (`css/js/png/jpg/svg/webp`) и включает `cleanUrls`, так что внутренние ссылки можно дополнительно писать без расширения `.html`, если захотите.

Альтернативно сайт можно опубликовать через `vercel` CLI:

```
npm i -g vercel
vercel login
vercel --prod
```

Команда из корня проекта сразу выложит файлы.
