# Šálek klidu — Bez bolesti hlavy

*Концепция и материалы для статического сайта выездного мастера по компьютерам.*

---

## 1. Концепция и ассоциации

Имя записи в Site content — **«Без головной боли»** (cs: *Bez bolesti hlavy*). Это не про железо — это про **облегчение, выдох, тишину в голове**.

Из названия и текстов выросли 3–5 ключевых ассоциаций:

1. **Выдох / облегчение.** Мастер снимает тревогу с плеч клиента.
2. **Чашка кофе пока мастер работает.** Тёплая, домашняя сцена.
3. **Спокойный сон** — алармы и камеры дают peace of mind.
4. **Соседская речь без жаргона** — "вы платите только за работу".
5. **Невидимая рутина** — техника наконец перестаёт мешать жить.

Отсюда визуальный язык: **«Šálek klidu»** («Чашка покоя») — кофейная кружка ☕ как иконка, тёплый кремовый фон, шалфейный акцент, тёплая бежевая «глазурь», засечковая антиква Fraunces для заголовков и спокойный Manrope для текста.

**Палитра:**

- `--bg: #FAF6EF` (кремовый фон, как латте)
- `--surface: #FFFFFF`
- `--ink: #2A241F` (тёмно-кофейный)
- `--ink-soft: #6A6259`
- `--line: #ECE4D6`
- `--accent: #7BA098` (шалфей)
- `--accent-dark: #4F7B71`
- `--warm: #E8C9A6` (тёплая бежевая глазурь)

**Типографика:** Fraunces (Google Fonts) для заголовков, Manrope для текста. Заголовки с курсивными вставками в акцентном цвете дают «человеческую», не-корпоративную интонацию.

- 12 страниц услуг — у каждой свой hero-вариант (`default`, `flip`, `wide`, `tall`) для разнообразия композиции; `--main.png` всегда в hero, `--hover.png` — во втором блоке как контекстное фото без hover-эффекта. В конце — карточка CTA и навигация *Předchozí / Další* по кругу (design → cleaning).

## 5. Развёртывание на Vercel

Сайт полностью статический — Vercel разворачивает его без конфигурации.

**Вариант A: CLI**

```bash
npm i -g vercel
vercel login
vercel            # первый деплой (preview)
vercel --prod     # продакшен
```

**Вариант B: Git + Dashboard**

1. Создать репозиторий на GitHub/GitLab и запушить папку.
2. На [vercel.com/new](http://vercel.com/new) импортировать репозиторий.
3. Framework Preset: **Other**. Build Command: пусто. Output Directory: `.` (корень).
4. Deploy.
5. В Settings → Domains добавить `bezbolestihlavy.cz` и направить DNS на Vercel (CNAME `cname.vercel-dns.com` или A `76.76.21.21`).

Файл `vercel.json` уже настраивает `cleanUrls`, длинный кеш для статики и базовые security-заголовки.
